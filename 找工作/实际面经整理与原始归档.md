## 一、基于当前简历的复习导航

### 1. FastDFS 云存储项目主线

- 项目定位：Linux 环境下的分布式文件存储系统，支持注册登录、上传、下载、删除、分享、转存和取消分享。
- 服务链路：Nginx 提供 HTTP 服务和反向代理，FastCGI 将入口层与动态业务服务连接起来。
- 数据分工：FastDFS 保存文件，MySQL 持久化用户、文件和分享关系，Redis 保存 Session 与热点数据。
- 核心难点：基于摘要的秒传、分片上传与合并、文件分享排行，以及存储节点负载均衡改进。
- 项目表达：个人职责、关键调用链、一致性、失败窗口、压测方法和可量化结果。

### 2. C++ 高频基础

- RAII、智能指针、`vector`、迭代器、模板和泛型。
- `static`、`const`、Lambda、左右值、移动语义、完美转发和结构化绑定。
- 虚函数、虚表、多态、构造析构、`new/malloc` 和内存泄漏。
- 多线程同步、原子操作、无锁结构、线程池、连接池和内存池。

### 3. 操作系统与 Linux

- 进程、线程、IPC、共享内存、锁、死锁和协程基本概念。
- 虚拟内存、缺页、内存布局、文件系统、程序装载和动态链接。
- `epoll`、`select`、Reactor、零拷贝、core dump 和 Socket 编程。
- `netstat`、`ss`、`tcpdump`、`arp`、`ip route`、`traceroute` 等网络排查命令。

### 4. 网络与 Web 服务

- TCP 三次握手、四次挥手、流量控制、拥塞控制、粘包和可靠传输。
- UDP、DNS、ICMP、ARP、HTTP、HTTPS、长连接、Cookie、Session 和 JWT。
- Nginx 反向代理、负载均衡、动静分离、配置文件和 worker 进程模型。
- FastCGI 请求转发、进程管理、响应返回，以及与普通 CGI 的区别。

### 5. 数据与存储

- MySQL 索引、事务、MVCC、锁、执行计划、主从复制和常见索引失效。
- Redis 数据结构、持久化、Session、热点数据、缓存策略和分布式锁。
- 秒传中的哈希冲突处理、文件元数据设计、分片状态管理和合并幂等。
- FastDFS Tracker、Storage、Group、文件定位、节点选择和故障处理。

### 6. RAG/Agent 扩展参考

- 只需了解基本用途、典型流程和常见术语，用于应对开放性追问。
- 不把向量库、模型编排、工具调用等内容描述为当前云存储项目的已实现模块。
- 回答时可以说“作为扩展方向了解过”，并主动把讨论拉回 Linux C++、存储和网络主线。
